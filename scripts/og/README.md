# OG images

`og.html` is the source for `public/og-home.png`, `public/og-blog.png` and `public/og-projects.png` (1200x630, light only).

To regenerate after editing `og.html`, from this directory with `playwright` available (`npx -p playwright node render.mjs ../../public` also works):

```
node render.mjs ../../public
```
